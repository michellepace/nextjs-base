# shadcn/ui — curated docs

Local copies of shadcn/ui docs, saved as markdown. Each file is a page's `.md` URL, such as `https://ui.shadcn.com/docs/theming.md`.

| File | Descrip |
| ---- | ------- |
| `llms-txt.md` | shadcn llms.txt index: doc URLs for install, components, dark mode, forms, MCP, registry |
| `installation-next.md` | Next.js setup: `init -t next`, `--preset`, `--monorepo`, shadcn/create, `add -c`, @/* alias |
| `components-json.md` | components.json keys: style, tailwind.css/baseColor/cssVariables/prefix, rsc, aliases, registries |
| `cli.md` | shadcn commands: init, add, apply, preset, view, search, build, docs, info, migrate, eject |
| `theming.md` | Token pairs (primary/primary-foreground), :root/.dark, @theme inline, --radius scale, new tokens, baseColor |
| `dark-mode-next.md` | next-themes ThemeProvider attribute="class", suppressHydrationWarning, useTheme ModeToggle |
| `tailwind-v4.md` | v4 upgrade: @theme inline, hsl→OKLCH, size-*, tw-animate-css, forwardRef removed, data-slot |
| `typography.md` | No shipped styles: utility-class recipes for h1–h4, p, blockquote, table, list, lead, muted |
| `typeset.md` | Markdown prose styling: typeset.css, .typeset presets, --typeset-size/leading/flow, not-typeset, typeset-scroll |
| `skills.md` | shadcn/ui agent skill: `npx skills add shadcn/ui`, project context via `shadcn info --json` |
| `mcp-server.md` | `shadcn mcp init --client` for Claude Code/Cursor/VS Code/Codex, .mcp.json, registries |
